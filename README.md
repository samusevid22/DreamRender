# Студия нейро-видео (`@local/neural-video-studio`)

Плагин DSH с собственной панелью в левой боковой панели. Вы описываете фильм — нейросеть
планирует сцены и пишет код отрисовки, а браузер рендерит его в видео **со звуком** длиной
**до 60 секунд**. Фильм можно бесконечно править словами и подключать свою 3D-модель, которую
плагин распознаёт и анимирует по частям (руки, ноги, голова, колёса, двери — что найдёт).

## Что он делает

1. **План.** Хост-половина просит модель (маршрут из настроек профиля: `agentDefaultModel`,
   иначе первый зарегистрированный провайдер) разбить замысел на 2–4 сцены.
2. **Код.** Для каждой сцены модель пишет рендерер:
   * `2d` — функцию `draw(ctx, W, H, t, duration)` для Canvas2D;
   * `3d` — фрагментный шейдер WebGL1 (`u_resolution`, `u_time`, `u_duration`, один `void main()`);
   * `mesh` — функцию `animate(t, duration)` для загруженной 3D-модели: поворот/масштаб,
     камера, свет, материал **и массив `parts` — повороты отдельных частей модели**.
3. **Звук.** Если звук включён, модель отдельно пишет `soundtrack(ctx, duration)` — код
   Web Audio (осцилляторы, шум, фильтры, огибающие). Браузер рендерит дорожку офлайн,
   склеивает дорожки сцен по таймлайну и записывает видео вместе со звуком (Opus/AAC).
   Дорожку можно скачать отдельно как `.wav`.
4. **Рендер.** Код компилируется в песочнице (`<iframe sandbox="allow-scripts">` без доступа к
   странице Harness), кадры рисуются и записываются `MediaRecorder` в реальном времени.
5. **Монтаж.** Кадры складываются в таймлайн: добавлять, двигать, удалять, править код любой
   сцены и рендерить заново; проект сохраняется в `.json`.
6. **Итерации.** Блок «Итерации»: «добавь дождь», «камера ближе», «сделай музыку тревожнее».
   Нетронутые сцены копируются как есть, изменённые переписываются на основе их текущего кода,
   звук правится только если попросить. Так можно править фильм сколько угодно раз.

## Своя 3D-модель: распознавание и артикуляция

Кнопка «Загрузить модель» принимает `.glb`, `.obj`, `.stl` (до 250 тыс. треугольников, 60 МБ).

* **Разбор:** glTF-узлы с трансформами, индексы и нормали (при отсутствии — фасетные), OBJ
  (`v//vn`, отрицательные индексы, n-угольники), STL (бинарный/ASCII).
* **Распознавание:** геометрия анализируется детерминированным k-means на 8 частей; считаются
  габариты, симметрия, вытянутость и «конечности». В карточке модели показывается предположение
  (гуманоид, существо, транспорт, предмет, архитектура), а план фильма уточняет его в `modelKind`.
* **Артикуляция:** для каждой части рендерер знает центр-пивот, размер, долю и зеркальную пару.
  Модель анимирует их через `parts: [{ i, rx, ry, rz, ox, oy, oz }]`: шаг с противоположными
  махами рук и ног, наклон и кивок головы, взмах, поворот колёс/турели, сборка-разборка — в
  зависимости от распознанного класса.
* **Реализм:** встроенный PBR-рендерер (GGX + fresnel + ambient), ACES-тонирование, гамма,
  антиалиасинг, контактная тень, туман, зерно, виньетка. Материал задаётся `tint`,
  `roughness`, `metalness`, `rim`.

## Звук и ограничения воспроизведения

* Звук генерируется кодом, без внешних файлов и голоса: эмбиент, шум, акценты, огибающие.
* Хост проверяет синтаксис JavaScript каждого сгенерированного кода до возврата в браузер.
* Браузер может потребовать один клик для включения звука (политика autoplay): панель покажет
  кнопки «Со звуком» / «Без звука» прямо в предпросмотре. При отказе или ошибке Web Audio
  видео всё равно запишется — без звука, с предупреждением.
* Итоговый контейнер: MP4, если браузер умеет записывать MP4 со звуком, иначе WebM (Opus).
  Длительность — до 60 секунд; запись идёт в реальном времени, поэтому 60-секундный фильм
  пишется примерно 60 секунд.

## Где это в интерфейсе

* Иконка **«Нейро-видео»** в левой боковой панели (рядом с «Плагинами» и «Расписаниями»).
* Страница студии: запрос, звук, загрузка модели, таймлайн с редактором кода, итерации,
  предпросмотр с кнопкой рендера.

## Встроенное демо

Кнопка **«Загрузить демо»** подставляет двухсценный фильм без обращения к модели: 2D-звёздное
поле и 3D-шейдер. Быстрый способ проверить рендер.

## Инструменты для агента

* `neural_video_generate` — создать проект (параметры как у формы; `mesh` включает mesh-сцены,
  `sound` включает звук).
* `neural_video_refine` — доработать проект одной инструкцией, возвращает обновлённый фильм.

## Настройки

Необязательные поля строки плагина в `cordis.patch.yml`:

```yaml
- id: neural-video-studio
  name: '@local/neural-video-studio'
  config:
    provider: deepseek-account   # маршрут модели, иначе agentDefaultModel профиля
    model: deepseek-flash
    timeoutMs: 300000            # общий дедлайн одной операции
```

## Ограничения

* Нужен зарегистрированный LLM-провайдер: генерация, правки, код сцен и звука идут через сервис `llm`.
* Загруженная модель живёт в памяти вкладки: фильм, звук и лог итераций переживают перезагрузку,
  модель после F5 нужно загрузить заново.
* Текстуры и материалы из GLB/OBJ не импортируются — модель затеняется встроенным материалом.
* Сгенерированный код исполняется только внутри sandbox-iframe без same-origin доступа.
