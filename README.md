# DreamRender
DreamRender is a plugin for Deepseek Harness that allows you to create full‑fledged videos using artificial intelligence.

DreamRender
A plugin for DeepSeek Harness (JS) that creates video based on a text description.

How it works
You send a text request — a video description.

DeepSeek Harness generates JS rendering code (Canvas, FFmpeg, or Remotion).

DreamRender executes this code in a sandbox.

The frames are assembled into MP4 via FFmpeg.

The finished file is saved to disk.
